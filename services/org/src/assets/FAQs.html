Overview Of Qualizen

Qualizen is a robust suite of micro-applications designed to streamline your project management and enhance your workflow. This guide provides step-by-step instructions on how to utilize key features and tools within Qualizen.

How to Create an Organization and Invite Users

To get started with Qualizen, follow these simple steps:

  • Register Your Organization – Provide the necessary details to set up your organization.
  • Create a Portfolio – Portfolios are high-level categories that help organize your projects.
  • Create a Project – Within a portfolio, create projects to manage specific tasks and goals.
  • Invite Users – Navigate to the project dashboard and invite users with one of the following roles:
    • Portfolio Admin: Access to all projects within the portfolio.
    • Project Admin: Access to a specific project with permissions to add user stories.
    • Read-Only User: View-only access to user stories.

How to Import or Add User Stories

  • Import User Stories – Import stories directly from an Excel file or integrate with Jira by providing:
    • Jira URL
    • Access Token
  • Manually Add User Stories – Add stories directly in the project dashboard for seamless integration into your workflow.

How to Use Qualizen Products

Kill Ambiguity

Tailor your platform to fit your specific needs with highly customizable options for identifying and refining ambiguities.

  1. Add a User Story: Enter or import a story into the system.
  2. Identify Ambiguities: Use the Agentic AI tool to detect ambiguities in your user story.
  3. Refine Your User Stories: Select specific ambiguities to refine your stories, generating:
    • Acceptance criteria
    • Assumptions
    • Refined user story created by Agentic AI

Mind Map Generator

Enhance your brainstorming with detailed mind maps, helping you create more structured and impactful strategies.

  1. Generate Mind Maps: Create comprehensive visualizations for user stories based on the following criteria:
    • Overview: Core functionality, user actions, expected outcomes, dependencies, alternative flows, and edge cases.
    • Reliability: System’s ability to function consistently without errors.
    • Availability: Accessibility and operational readiness.
    • Scalability: Handling increased load efficiently.
    • Resilience: Recovery from disruptions or failures.
    • System Components: Core system elements required for the user story.

Test Scenarios Generator

Generate realistic test scenarios to validate ideas and strategies with ease.

  1. Select a User Story: Choose a story to test.
  2. Generate Test Scenarios: Click "Process" and let Agentic AI create:
    • Positive and negative test scenarios
    • Functionality testing
    • Performance testing
    • Security testing

Qualizen FAQs

What is Qualizen?

Qualizen is a suite of micro-applications designed for effective project management, offering tools like the Ambiguity Killer, Mind Map Generator, and Test Scenarios Generator.

Who can use Qualizen?

Teams, organizations, and individuals managing complex projects or workflows can benefit from Qualizen’s features.

Is Qualizen customizable?

Yes, you can tailor Qualizen’s tools, such as defining custom roles, user access, and integrations, to fit your organizational needs.

How do I register my organization?

Visit the registration page, fill in your organization details, and click Register to create your organization.

What is a portfolio in Qualizen?

A portfolio is a collection of related projects within your organization, allowing you to organize and manage multiple projects efficiently.

How do I create my first project?

Navigate to your portfolio, go to the Projects tab, and click New Project to set it up with relevant details like name and description.

What file formats are mind maps available in?

Generated mind maps will be available in PNG format.

How does the Test Scenarios Generator work?

It uses AI to create positive and negative test scenarios for functionality, performance, security testing, and more dynamic scenarios.

What types of tests does it support?

It supports functionality, performance, and security testing, among others.

What roles can I assign to users?

Roles include Portfolio Admin, Project Admin, and Read-Only User. Each role has distinct permissions tailored to specific responsibilities.

Can I import user stories into Qualizen?

Yes, you can import user stories from Excel files or Jira. For Jira, provide the URL and token for seamless integration.

What details are required to manually add a user story?

Title, description, and priority are mandatory. Additional fields include tags and assignees.

Can I edit user stories after they are created?

Yes, you can edit or delete user stories directly in the project dashboard.

What does the Kill Ambiguity do?

It identifies unclear aspects of user stories and refines them using AI-generated suggestions for acceptance criteria and assumptions.

How do I refine a user story?

Use the AI tool to flag ambiguities, select suggestions, and save the updated story.

Does the Kill Ambiguity provide acceptance criteria?

Yes, it generates detailed acceptance criteria to ensure clarity and completeness in your user stories.

What are mind maps used for?

Mind maps provide a visual representation of user stories, covering aspects like functionality, reliability, and scalability.

How can I generate Mind Maps for different aspects?

You can select different tabs like functionality, reliability, and scalability, and click on generate to generate mind maps based on those aspects.
